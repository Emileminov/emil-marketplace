# Emil Marketplace - моды для Claude

Каталог модов для Claude Code (приложение Claude, вкладка Code).

## Как подключить каталог

1. Открой Claude, вкладка **Code**.
2. Нажми **+** рядом с полем ввода, выбери **Plugins**.
3. **Add marketplace**, вставь: `Emileminov/emil-marketplace`.
4. Дальше выбирай нужный мод из списка (**Add plugin**), область **user**.
5. Открой новую сессию и напиши любое сообщение. Мод заработает.

## Моды

| Мод | Что делает |
| --- | --- |
| [pixel-city](plugins/pixel-city) | Пиксельный город над полем ввода: Клодик показывает лимиты 5 часов, неделя, контекст и время до сброса |
| [klodik-live](plugins/klodik-live) | Живой комментатор: Клодик простым языком показывает, что Claude делает прямо сейчас |
