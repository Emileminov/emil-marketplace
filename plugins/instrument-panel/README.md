# Instrument Panel - инженерная панель для Claude

Строгая приборная панель над полем ввода, без мультяшности. Тёмная, с измерительной сеткой.

**Слева - состояние Claude**, как у станка: СТАТУС и номер шага, индикатор-лампа и слово состояния (ОЖИДАНИЕ, ОБРАБОТКА, ЧТЕНИЕ, ПРАВКА, ЗАПИСЬ, ВЫПОЛНЕНИЕ, ПОИСК, ПОДЗАДАЧА, ЗАВЕРШЕНО, СБОЙ), ниже имя файла или команды.

**Справа - три сегментные шкалы**: 5 ЧАСОВ, НЕДЕЛЯ, КОНТЕКСТ (память чата). Зелёная зона до 70%, жёлтая до 90%, красная выше, на шкале отметки 70% и 90%. Рядом процент и `ЧЕРЕЗ 4:29` - когда лимит обновится (4 часа 29 минут, `ЧЕРЕЗ 1,5 ДН` - через полтора дня).

- лимиты 5 часов и недели видны только на подписке Claude (Pro / Max). Без неё эти шкалы пустые, а работает только «Контекст»;
- если лимит почти исчерпан (90%+), в ожидании панель пишет красным ЛИМИТ НА ИСХОДЕ;
- дружит с `pixel-city`: если стоят оба, полосы встают друг под другом. Для одной полосы оставь один из модов.

## Установка

1. Claude, вкладка **Code**, кнопка **+** рядом с полем ввода, **Plugins**.
2. **Add marketplace**, вставь: `Emileminov/emil-marketplace`.
3. **Add plugin**, выбери `instrument-panel`, область **user**.
4. Открой новую сессию и дай Claude любую задачу.
