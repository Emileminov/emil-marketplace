# Klodik Live - живой комментатор

Над полем ввода пиксельный Клодик простым русским языком показывает, что Claude делает прямо сейчас: «ЧИТАЮ ФАЙЛ index.html», «ПРАВЛЮ ФАЙЛ style.css», «ЗАПУСКАЮ КОМАНДУ», «ИЩУ В ИНТЕРНЕТЕ», «ДУМАЮ», «ГОТОВО». Справа счётчик шагов, а на дорожке внизу цветные точки: по одной на каждый шаг (серый - чтение, коралловый - правка, жёлтый - команды, зелёный - поиск, красный - ошибка).

Дружит с модом `pixel-city`: если стоят оба, полосы встают друг под другом.

## Установка

1. Claude, вкладка **Code**, кнопка **+** рядом с полем ввода, **Plugins**.
2. **Add marketplace**, вставь: `Emileminov/emil-marketplace`.
3. **Add plugin**, выбери `klodik-live`, область **user**.
4. Открой новую сессию и дай Claude любую задачу.
