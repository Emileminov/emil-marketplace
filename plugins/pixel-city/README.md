# Pixel City - Клодик показывает твои лимиты

Мод для Claude Code. Над полем ввода появляется тёмная пиксельная полоска с городом: три башни показывают, сколько израсходовано лимита за 5 часов, за неделю и сколько заполнено окно чата (контекст). Под каждым лимитом написано, через сколько он сбросится. Клодик ходит рядом и меняет настроение: `OK`, `?`, `!!`.

- окна башни загораются по мере расхода: зелёные до 70%, жёлтые до 90%, красные выше;
- `СБРОС 4Ч29М` - лимит обновится через 4 часа 29 минут, `3Д4Ч` - через 3 дня 4 часа;
- лимиты 5 часов и недели видны только на подписке Claude (Pro / Max). Без неё эти башни тёмные, а работает только «Контекст».

## Установка

Нужна свежая версия Claude Code (приложение Claude, вкладка Code).

1. Нажми **+** рядом с полем ввода, выбери **Plugins**.
2. **Add marketplace**, вставь: `Emileminov/emil-marketplace`.
3. **Add plugin**, выбери `pixel-city`, область **user**.
4. Открой новую сессию и напиши любое сообщение. Город появится над полем ввода.

## Удалить

```bash
claude plugin uninstall pixel-city@emil-marketplace
```
