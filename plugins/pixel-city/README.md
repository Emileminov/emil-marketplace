# Pixel City - Клодик показывает твои лимиты

Мод для Claude Code. Над полем ввода одна тёмная пиксельная полоса.

**Слева - что Claude делает прямо сейчас.** Клодик со своим занятием и подписью простым языком: ДУМАЮ, ЧИТАЮ (имя файла), ПРАВЛЮ, ПИШУ, КОМАНДА, ИЩУ, ИЩУ В СЕТИ, ПОМОЩНИК, ГОТОВО (сколько было шагов). Внизу дорожка из цветных точек, по одной на шаг: серый - чтение, коралловый - правка, жёлтый - команды, зелёный - поиск, красный - ошибка.

**Справа - лимиты.** Три башни: 5 ЧАСОВ, НЕДЕЛЯ, КОНТЕКСТ (сколько заполнено окно чата). Окна загораются по мере расхода: зелёные до 70%, жёлтые до 90%, красные выше. Под лимитом время до сброса: `СБРОС 4Ч29М` - через 4 часа 29 минут, `3Д4Ч` - через 3 дня 4 часа.

- лимиты 5 часов и недели видны только на подписке Claude (Pro / Max). Без неё эти башни тёмные, а работает только «Контекст»;
- если лимит почти исчерпан (90%+), в ожидании Клодик пишет красным МАЛО ЛИМИТА.

## Установка

Нужна свежая версия Claude Code (приложение Claude, вкладка Code).

1. Нажми **+** рядом с полем ввода, выбери **Plugins**.
2. **Add marketplace**, вставь: `Emileminov/emil-marketplace`.
3. **Add plugin**, выбери `pixel-city`, область **user**.
4. Открой новую сессию и напиши любое сообщение. Город появится над полем ввода.

## Удалить

```bash
claude plugin uninstall pixel-city@emil-marketplace
```
